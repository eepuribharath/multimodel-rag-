Drop your documents here, then run (from the project root):

    venv/bin/python scripts/ingest_library.py

Supported: .md .txt .rst .pdf  |  images: .png .jpg .jpeg .gif .webp
audio: .wav (.mp3/.m4a need ffmpeg installed)  |  subfolders are fine

Re-running is safe — files you already ingested are updated, not duplicated.
